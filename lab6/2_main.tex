\chapter{Лабораторная работа №6. $H_{\infty}$-оптимизация}

\section*{Постановка (вариант 13)}
Возмущённый объект
\[
\dot x = A x + B u + B_f f,\qquad x(0)=\begin{bmatrix}1\\0\end{bmatrix},
\]
\[
A=\begin{bmatrix}0&1\\4&0\end{bmatrix},\quad B=\begin{bmatrix}2\\6\end{bmatrix},\quad B_f=\begin{bmatrix}0\\2\end{bmatrix},\quad Q=I_2.
\]
Возмущение для моделирования:
\[
 f(t)=10\sin 6t+5\cos 2t+4\cos 3t+3\cos 8t.
\]
Требуется синтезировать $H_{\infty}$-регулятор $u=Kx$ по уравнению Риккати
\[
A^T P + P A + Q - P B B^T P + \frac{1}{\gamma^2} P B_f B_f^T P = 0,\qquad K=-B^T P,
\]
и экспериментально определить минимальное $\gamma_{\min}$, при котором существует стабилизирующее решение $P\succeq0$.

\section{Численная реализация}
Используем итерационный алгоритм: при фиксированном $\gamma$ решаем стандартное CARE
\[
A^T P_{k+1}+P_{k+1}A - P_{k+1} B B^T P_{k+1} + (Q + \tfrac{1}{\gamma^2} P_k B_f B_f^T P_k)=0
\]
с начальным $P_0$ из LQR (решение CARE с $Q$ и $R=I$). Затем по адаптивному поиску подбираем $\gamma$ так, чтобы матрица $A+BK$ была устойчивой и $P\succeq0$. Для найденного $\gamma_{\min}$ моделируем $x_1,x_2,u$ и вычисляем частотные зависимости трёх каналов:
\[
G_1(j\omega)=C_1(j\omega I-A_{cl})^{-1}B_f,\quad
G_2(j\omega)=C_2(j\omega I-A_{cl})^{-1}B_f,
\]
\[
G_f(j\omega)=(j\omega I-A_{cl})^{-1}B_f,\quad
G_u(j\omega)=(j\omega I-A_{cl})^{-1}B,
\]
где $C_1=[1\;0]$, $C_2=[0\;1]$. Максимумы $G_1,G_2$ дают нормы по компонентам, $G_f$ соответствует требуемой в п.~6 совокупной реакции на возмущение, $G_u$ — на управляющий вход.

# lab6/python/hinf_var13.py
import numpy as np
from scipy.linalg import solve_continuous_are, eigvals
from scipy.integrate import solve_ivp
import matplotlib.pyplot as plt

A = np.array([[0.0, 1.0],[4.0, 0.0]])
B = np.array([[2.0],[6.0]])
Bf = np.array([[0.0],[2.0]])
Q = np.eye(2)

# LQR as initial P
P0 = solve_continuous_are(A, B, Q, np.eye(1))


def solve_hinf_fixed_gamma(gamma: float, iters: int = 30, tol: float = 1e-10):
    P = P0.copy()
    for _ in range(iters):
        Qeff = Q + (1.0/(gamma**2)) * (P @ Bf @ Bf.T @ P)
        P_next = solve_continuous_are(A, B, Qeff, np.eye(1))
        if np.linalg.norm(P_next - P, ord='fro') < tol:
            P = P_next
            break
        P = P_next
    K = -(B.T @ P)
    Acl = A + B @ K  # since u=Kx
    return P, K, Acl


def find_gamma_min(gmin=1e-3, gmax=1e2):
    lo, hi = gmin, gmax
    for _ in range(40):
        mid = np.sqrt(lo*hi)
        P, K, Acl = solve_hinf_fixed_gamma(mid)
        stable = np.all(np.real(eigvals(Acl)) < -1e-6)
        if stable:
            hi = mid
        else:
            lo = mid
    return hi, solve_hinf_fixed_gamma(hi)


gamma_min, (P, K, Acl) = find_gamma_min()
print({"gamma_min": float(gamma_min), "K": K.tolist(), "eig(A+BK)": eigvals(Acl)})
# Result: gamma_min = 0.1, K = [[10412.53, -11113.65]], eig(A+BK) = [-0.576, -45856.3]

\section{Множество сингулярных чисел замкнутой системы}

Для замкнутой системы с $H_{\infty}$-регулятором передаточная функция от возмущения $f$ к состоянию $x$ имеет вид
\[
G(s) = (sI - A_{cl})^{-1} B_f,
\]
где $A_{cl} = A + BK$ — замкнутая матрица системы.

\subsection{Математическое определение множества сингулярных чисел}

Множество сингулярных чисел передаточной функции $G(s)$ определяется как множество всех сингулярных чисел матрицы $G(j\omega)$ при всех частотах $\omega \in \mathbb{R}$:
\[
\sigma(G) = \left\{ \sigma(\omega) : \omega \in \mathbb{R} \right\},
\]
где $\sigma(\omega)$ — функция сингулярного числа, вычисляемая следующим образом.

Для каждой частоты $\omega \in \mathbb{R}$ вычисляется матрица передаточной функции на мнимой оси:
\[
G(j\omega) = (j\omega I - A_{cl})^{-1} B_f.
\]
Матрица $G(j\omega)$ имеет размерность $n \times m$, где $n=2$ — размерность состояния, $m=1$ — размерность возмущения.

Сингулярные числа матрицы $G(j\omega)$ находятся через сингулярное разложение (SVD):
\[
G(j\omega) = U(\omega) \Sigma(\omega) V^*(\omega),
\]
где $U(\omega)$ и $V(\omega)$ — унитарные матрицы, а $\Sigma(\omega) = \operatorname{diag}(\sigma_1(\omega), \sigma_2(\omega), \ldots)$ — диагональная матрица сингулярных чисел, упорядоченных по убыванию:
\[
\sigma_1(\omega) \geq \sigma_2(\omega) \geq \cdots \geq 0.
\]

Функция сингулярного числа определяется как максимальное сингулярное число:
\[
\sigma(\omega) = \sigma_{\max}(G(j\omega)) = \sigma_1(\omega) = \max \left\{ \sigma_i(\omega) : i = 1, 2, \ldots \right\}.
\]

Альтернативно, сингулярные числа можно вычислить через собственные значения эрмитовой матрицы:
\[
\sigma_i^2(\omega) = \lambda_i\left( G^*(j\omega) G(j\omega) \right),
\]
где $G^*(j\omega) = \overline{G^T(j\omega)}$ — эрмитово сопряжённая матрица, а $\lambda_i(\cdot)$ — $i$-е собственное значение.

\subsection{Связь с $H_{\infty}$-нормой}

$H_{\infty}$-норма передаточной функции равна максимуму множества сингулярных чисел:
\[
\|G\|_{\infty} = \sup_{\omega \in \mathbb{R}} \sigma(\omega) = \max_{\omega \in \mathbb{R}} \sigma(\omega).
\]
Это следует из определения $H_{\infty}$-нормы как максимального сингулярного числа передаточной функции на мнимой оси.

\subsection{Численная реализация}

Для численного вычисления множества сингулярных чисел написан скрипт \texttt{python/singular\_values.py}, который:
\begin{enumerate}
\item Синтезирует $H_{\infty}$-регулятор для найденного $\gamma_{\min}$;
\item Вычисляет замкнутую матрицу $A_{cl} = A + BK$;
\item Для сетки частот $\omega \in [10^{-2}, 10^{2}]$ рад/с вычисляет матрицу $G(j\omega)$;
\item Находит сингулярные числа через SVD: $G(j\omega) = U(\omega) \Sigma(\omega) V^*(\omega)$;
\item Определяет функцию $\sigma(\omega) = \sigma_{\max}(G(j\omega))$;
\item Вычисляет $H_{\infty}$-норму как максимум функции $\sigma(\omega)$.
\end{enumerate}

Результаты вычислений представлены на рис.~\ref{fig:singular-values}. График показывает зависимость максимального сингулярного числа $\sigma(\omega)$ от частоты $\omega$. Видно, что максимум достигается при низкой частоте $\omega = 0.01$ рад/с и равен $H_{\infty}$-норме $\|G\|_{\infty} = 2.304$.

\subsection{Численные результаты}

Численное вычисление даёт следующие результаты:
\begin{itemize}
\item Множество сингулярных чисел: $\sigma(G) = \{\sigma(\omega) : \omega \in [10^{-2}, 10^{2}] \text{ рад/с}\}$;
\item Максимальное значение функции: $\max_{\omega} \sigma(\omega) = 2.304$;
\item Частота максимума: $\omega_{\max} = 0.01$ рад/с;
\item $H_{\infty}$-норма: $\|G\|_{\infty} = 2.304$ (совпадает с результатом из табл.~\ref{tab:hinf-norms}).
\end{itemize}

Функция $\sigma(\omega)$ монотонно убывает с ростом частоты, что соответствует физическому смыслу: система лучше подавляет низкочастотные возмущения, чем высокочастотные.

Численное решение даёт следующие результаты:
\begin{itemize}
\item Минимальное значение параметра: $\gamma_{\min} = 0.1$
\item Матрица усиления: $K = \begin{bmatrix} 10412.53 & -11113.65 \end{bmatrix}$

\item $H_{\infty}$-нормы каналов: $\|G_1\|_{\infty}=1.682$, $\|G_2\|_{\infty}=1.576$, $\|G_f\|_{\infty}=2.304$, $\|G_u\|_{\infty}=3.78\cdot10^{-4}$
\item Множество сингулярных чисел: $\sigma(G) = \{\sigma(\omega) : \omega \in \mathbb{R}\}$, где $\sigma(\omega) = \sigma_{\max}((j\omega I - A_{cl})^{-1} B_f)$
\end{itemize}
Замкнутая система устойчива (все собственные значения отрицательны), что подтверждает корректность синтеза $H_{\infty}$-регулятора.
